项目简介

这是一个基于现代技术栈构建的全栈博客系统。前端采用 React 框架，提供流畅的用户体验；后端使用 Go 语言开发，保证高性能和高并发处理能力。

系统支持 Markdown 格式的文章编写，内置代码高亮功能，适合技术博客内容的展示。同时集成了评论系统、标签分类、文章搜索等实用功能。

核心功能

  • • Markdown 编辑器，支持实时预览和代码高亮
  • • 文章分类和标签管理系统
  • • 全文搜索功能，快速定位内容
  • • 评论系统，支持多级回复
  • • 响应式设计，适配移动端和桌面端
  • • 后台管理系统，便捷的内容管理
  • • SEO 优化，提升搜索引擎排名

技术实现

前端架构：使用 React 18 和 React Router 构建单页应用，采用 Hooks 进行状态管理，通过 Axios 与后端 API 通信。

后端架构：基于 Go 语言的 Gin 框架开发 RESTful API，使用 GORM 作为 ORM 框架，实现数据持久化。

数据库设计：采用 MySQL 数据库存储文章、用户、评论等数据，通过索引优化查询性能。
